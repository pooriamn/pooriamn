# Portfolio website source

A dependency-free static portfolio. Preview locally with:

```sh
python -m http.server 8000 --directory docs
```

Open http://localhost:8000. To publish, enable GitHub Pages in repository Settings → Pages, select Deploy from a branch, main, /docs. The project site will then normally use https://pooriamn.github.io/pooriamn/. A separate repository named pooriamn.github.io would be needed for the standard root user site. No Pages activation is assumed.
